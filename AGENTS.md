# Repository instructions

## README

`README.md` is the public introduction for someone discovering Padra for the first
time. Document only the current engine: supported features, model/artifact and
hardware requirements, build/run instructions, API and operating contracts, and
current limitations or qualification status.

Do not use the README as a changelog, work log, review response or implementation
history. Do not describe past fixes, compare development stages, refer to reviews,
or recount optimization experiments there. Put change history and detailed test,
benchmark or review evidence in separate documents. Apply the same principle to
other README files: describe their current component or workflow.

When behavior changes, update the corresponding description of the current
behavior directly. Avoid adding a historical “what changed” paragraph.
