Shared Q8 output-head qualification — 2026-10-25

Decision: use one stored Q8-block32 head as the default of the new GPU profiles.
Deprecate BF16-head distribution for these profiles; retain legacy BF16 loading
as a compatibility and numerical-quality reference. This is a scoped engineering
decision, not a claim of general coding-quality equivalence.

Format and storage
INT8 codes -127..127, blocks of 32, BF16 positive scales, FP32 division and
round-to-nearest-even. The entire shared head has SHA256
0fa4891dcd9443a3d36d8d31d5f777c1cc06339eb1782855d86587cad276d587.
The stored checkpoint equals the existing C++ host converter byte-for-byte.
All 5630 other target tensors are unchanged for each K3/K4/K6 checkpoint.
Head payload:240648192 bytes (229.5 MiB), saving212336640 bytes (202.5 MiB).
Target and draft use the same GPU allocation. Stored artifacts require no head
quantization or repack on startup. No BF16 GPU shadow is retained.

Paired head-quality experiment
32 frozen documents:24 authored code snippets in 8 languages plus 8 repository
source files. Evaluate19657 next-token positions per configuration after the
first16/64 tokens, with at most4096 tokens per document. Feed the same captured
hidden vector to both heads. The diagnostic probe temporarily loads both heads
only for this comparison; the production engine owns exactly one. Final-row
logits are checked against the real runtime. This measures the complete Q8 head
path, including input quantization and accumulation, not weight error alone.

Top1 agreement describes one-step decisions on identical hidden states; it is
not sequence equivalence or an estimate of task success. Small logit changes
can change a generated sequence. These documents are not a held-out public
benchmark and do not establish quality at 131K context.

Engineering gates were frozen before execution:mean KL<=0.001, mean NLL
delta<=0.01, top1 agreement>=98.5%, no loss of functional passes. They are
engineering screening criteria, not user-specified quality guarantees. The
completed comparisons satisfy those gates. No extra failed functional case
appeared with Q8 in the completed paired tests.

Integrity and correctness
Native loading validates format, block size, scale type, complete weight hash,
head hash and all regions. Three valid stored artifacts and ten malformed
metadata cases were exercised.315 native request/depth combinations compare
stored Q8 with the former runtime-converted head exactly in token IDs, final
logits/hidden state, callbacks and committed/pending state. Independent MTP
verifier and memory qualification is recorded in gpu-profiles-2026-10-25.txt.
Offline MTP import against the stored-Q8 K4 target reproduces the original
BF16/F32 draft payload b03d5abcf0adf5f5089694668f723fb262f78dc104aeb14dcd00be7db40b8389.
