131K/MTP GPU profile qualification — 2026-10-25

Tested hardware:NVIDIA GeForce RTX 5080 Laptop GPU, SM120a,16 GiB class.

8/12 GiB cards, Pascal/GTX1070 and other architectures are not qualified.

profiles and a starting point for architecture ports, not cross-GPU speed claims.

Full-context tests use repeated natural code:131040 prompt tokens with up to32
outputs (normal EOS), then131071 prompt tokens and one output. D0/D1 token,
final-logit, hidden, callback and committed/pending states must match exactly.
This checks allocation and execution to the capacity boundary, not long-context
retrieval/coding quality. Full-context timing during concurrent CPU/network
publication work is not used as a performance benchmark.
