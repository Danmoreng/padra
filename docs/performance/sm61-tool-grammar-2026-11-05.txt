Implementation and validation
-----------------------------
- Lazy byte grammar follows initial thinking and activates at visible tool-call
  markers. It constrains offered names, JSON syntax and supported structural
  schemas. Full JSON Schema strict mode remains unsupported.
- Forbidden candidates are excluded before top-k/top-p or greedy selection.
  Source logits remain immutable and RNG advances once per target token.
- MTP proposals remain unconstrained. Only target choices advance grammar state;
  accepted proposals must match those target choices. Rejected speculative rows
  do not advance the grammar.
- Each HTTP request has fresh grammar state, including KV checkpoint restores.
- The additional admitted GPU allocation is 98,304 bytes. Vocabulary masks have
  a bounded CPU cache per request. No model weights or KV precision changed.

27/27 host tests pass. Grammar regression tests also pass under ASan/UBSan.
The model-free CUDA test passes greedy/stochastic masks, top-k ordering, RNG

are in G/evaluation/. Tests run only after all engine timing measurements.

llama.cpp: ID-selector display:flex overrides .hidden, so all overlays are
visible and normal Start is intercepted. A controlled start yields time=NaN
because gameLoop is called without a timestamp. Three controlled hits reach
zero shields without game over, and score10000 does not win. P/Escape do not
pause normal play; resume/restart add animation chains. Touch controls and
personal-record storage are absent.

Syntax validity and successful tool execution do not imply these games are
usable. No composite quality score or claim of engine-caused quality difference
is made from this single pair of runs with different quantizations.

Recommended optimization order
------------------------------
1. Profile and share compiled grammar/mask caches across identical tool schemas
   and tokenizer identities, retaining fresh mutable state per request. Consider
   vocabulary tries and avoiding redundant mask transfers. Preserve masking
   before top-k/top-p, exact sampling, cancellation isolation and MTP semantics.
   This targets the observed decode cost without changing model arithmetic.
2. Select bounded prefill attention by actual populated prefix length even when
   capacity131072 is reserved. Current SM61 bounded shapes require capacity8192;
   SGEMM attention requires capacity<=16384. Short prompts at131K therefore take
   the split attention path. Qualify any new dispatch with Q8 cache arithmetic,
   memory admission and growing-context tests.
3. Measure reusable generated KV suffixes at successful tool-turn boundaries.
   Current prompt snapshots and256-token chunk alignment leave fresh work on
   follow-up requests. Extend reuse only where canonical token-prefix matching
   proves it valid; preserve owner separation, cancellation and rollback.
4. Reassess MTP proposal masking and kernel tuning after those costs are isolated.
   Keep browser quality as a separate acceptance criterion and add quantization-
   matched/repeated runs before attributing model quality to an engine.
